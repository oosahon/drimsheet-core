# Implement Plan

## Load

- [Pair Programmer](../pair-programmer/SKILL.md)
- [Plan Implementation Workflow](../../workflow/plan-implementation.md)
- [Precedent And Deviation](../../rules/precedent-and-deviation.md)

## Work

- Follow the plan implementation workflow completely before editing.
- Treat the plan as the intended outcome, not as authority over current rules,
  code, or established patterns.
- Do not silently resolve assumptions, introduce precedent-free patterns, drift
  from scope, or include optional improvements.
- Finish with a plan-to-diff reconciliation and report every approved deviation.
