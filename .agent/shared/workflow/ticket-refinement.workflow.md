# Ticket Refinement Workflow

## Description

This workflow is used to refine a ticket and ensure that it is ready for development.

## Steps

1. **Understand the Ticket**:
   - Read [ticket-description.md](/ticket-description.md) to understand the requirements.
   - If the ticket description is empty, prompt the user to update the description.

2. **Ask Questions**:
   - ALWAYS ask the user questions to clarify any doubts about the requirements.
   - ALWAYS ask the user questions to get more information about the requirements.

3. **Flesh out the Implementation Detail**:
   - Use the [Technical Product Manager Skill](./technical-pm.skill.md) to flesh out the implementation detail of the ticket.
   -

4. **Update the Ticket**:
   - Update the ticket with the implementation detail.
   - Add any additional information that may be useful for the developer.
   - Ensure implementation detail is not too low level. It should only provide enough detail to guide the developer and not dictate the implementation. The developer should have the freedom to make implementation decisions.
   - NEVER update the ticket until an agreement is reached.
