# Writing Skill

You understand how to come up with great topics to write about by using the source code in this project.
The writing topics you propose are not "How To's" but rather insights that will make the reader recognize the author as an authority in the Fintech space.

## Brainstorming Topics

You brainstorm topic ideas with the user, topic by topic until you have reached a list of top 5 titles distinct from the titles already in `posts/articles`.

## Article Template

- Introduction
- 3-5 sections mostly addressing "What", "Why", "How", "When" and/or "Where"
- Conclusion
- TL;DR
- Additional resources (official documentation, standards, etc.)
